# 民航数字报读专项

依据用户提供的 [MH/T 4014—2003 PDF](https://www.caac.gov.cn/XXGK/XXGK/BZGF/HYBZ/201511/P020170804579259214829.pdf) 第3.4.1.1条表1（PDF物理第12页），已目视核对：0洞、1幺、2两、3三、4四、5五、6六、7拐、8八、9九。本次重点为1/2/7/0。引用不表示已核验该2003版现行有效性，也不表示已实现高度、频率、小数及所有特殊数字读法。

## 使用
1. 前后端同时更新到此版本，Render 保持已启用的 Vosk；无需新增密钥、GPU或付费服务。
2. 主界面上传/选择录音，在“识别策略”选择“数字报读专项（仅数字短句）”。
3. 录入数字短句开始秒和结束秒，最多30秒。只圈定逐位报读的数字，不把整段指挥通话放入数字解码器。
4. 开始识别，按播放时钟逐片输入模型，输出 Partial/Final；保留原始模型文字，另显示待核实数字候选和规范读法。时间戳对应原始文件，不从剪辑起点重新编号。
5. 进入该片段“参考规范与单卡修订”，点击“生成数字候选”，回听原录音，逐位核对后勾选确认并“采用已核实数字”。模型的词时间戳可能不包含漏识别的尾字，可用“打开完整原录音”核对片段前后声音。保留前导零、原文、版本及确认记录；事件仍待核实，不自动补呼号或位置。

完整救援对话继续使用“常规通话”。普通模式仅对明确的完整报读数字串提供字面候选；“两架飞机”“拐弯”“洞口”不作全局替换。混合句中的数字可通过上述选段专项复核，或回听后人工修改。专项同样可能听错，不能把受限词表结果当作独立音频证据。

## 实现和资源
使用同一 Vosk 小模型的独立 KaldiRecognizer，通过受限语法在解码阶段覆盖全部相邻数字组合和重复数字；不是先做全文转写后改显示，不是模型微调或原生热词 boosting。保留 [unk]；若结果含未知词或不是完整数字串，不输出完整号码。模型未提供某个数字的声学词条时明确报错。

除标准字形外，专项允许同音声学词条（例如“腰/邀”对应幺，“栋”对应洞）作为底层解码的词典桥接。这些字形不是新增标准读法；原始输出保留，转换仅作为须人工确认的候选。通用解码不会套用同音替换。

继续复用模型权重和默认单会话资源限制，不并行加载第二个模型。占用时返回 ASR_BUSY，其他引擎和旧版本不静默回退。受限数字词表会降低普通句子的识别能力，因此只用于用户圈定的数字短句。

## 验证边界
单元/接口测试覆盖映射、同音词仅限专项、重复数字转移、未知词、前导零、音频偏移、源时长、回听确认、陈旧版本及审计。浏览器测试覆盖人工候选确认；Real ASR 工作流另外合成自写“幺两拐洞”，通过实际模型和WebSocket检查，报告原始输出及候选，再执行专项浏览器选段。

合成音使用 MIT 许可的 MeloTTS 中文神经语音，测试内容由项目自写，不使用用户私密通信。按上游的音素/声调输入及模型说话人配置，慢读生成带停顿的“幺，两，拐，洞。”，检查有效长度和音量；每轮保留音频、SHA256与生成参数，便于下载同一音频复放。测试模型及配套文件固定到上游提交，并逐个校验 SHA256；其权重和 ONNX Runtime 仅用于 CI 生成测试音频，不加入 Render 镜像或运行依赖。许可见 tests/fixtures/MELOTTS-LICENSE.txt，固定来源和文字见 radio-tts-model.json。

早期 eSpeak 样例曾返回未知词，切换拼音发音后仍漏掉末尾0，未据此宣布验收通过；没有按预期号码补齐结果。神经合成样例同样不是代表性人声/无线电数据。以CI实际观察结果为准，不根据合成测试声称机场数字准确率或相对提升幅度。需要有授权的真实数字录音及独立测试集，才能评估数字错误率和噪声鲁棒性。
