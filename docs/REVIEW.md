# 事件分析与修订如何生效

右侧为规则分析，尚未启用 LLM。只分析 Final 和人工转写，不把 Partial 或 Mock 字幕当作事件证据。没有明确事件信息的普通对话会提示“已分析，信息不足”，保持未知。

当前会话按时间轴保留所有片段的分析，同一字段显示最近一次明确提及；不是多事件关联或事件关闭推理。后续“收到”不会清空先前已提取的地点。回听后修订某片段，删除的事实会从该片段的分析中撤回；其他片段仍有提及时仍会保留对应依据。可展开字段查看所用转写、音频时间范围和修订版本。所有规则结果仍待核实，人工编辑并不自动确认事件为事实。

## 主界面
1. 开始真实识别，或打开“历史识别会话”→“刷新历史”并选择会话。转写和事件分析一同加载。
2. 在通话记录的“人工修订”中修改后，点击“保存修订并更新分析”。仅输入文字不会保存。
3. 正文显示修订稿；原始文本保持可见。右侧自动更新，可用“刷新当前分析”重新加载。
4. 另一标签页修改后，切回识别台会在非识别运行期间刷新当前会话。

## 对话修订工作台
选择片段、回听、编辑“修订稿”并保存，或核实资料摘录、生成建议、回听确认后应用选中的术语修订。保存后右栏预览更新后的事件信息，并保留修改历史；点击“返回识别台”会回到对应会话。

PDF、单卡和错字映射用于提供有依据的参考建议；不会直接变成录音内容。当前只允许有限通用术语的单字错写映射。涉及呼号、位置、数字、否定词和指令的更正须结合音频人工修改。

## 为什么添加热词后识别不一定改善
Vosk 中文小模型当前不具备本项目的原生热词加权；“专业术语与热词词典”仅保存配置。人工修订改变当前片段的显示与分析，不会微调模型，也不会修改其他录音。需要提升机场无线电识别能力时，应另行评估模型、原生热词适配和有授权的术语数据，不能把保存词典描述为模型已学习。

规则已覆盖十个字段的部分明确表达，例如“27号跑道”“三级应急”“2人受伤”“需要2辆消防车”“请立即撤离”。车辆被提及或已到场，不直接推断为资源需求。只保留实际出现的文字；没有出现的内容为 null。常见否定表达已过滤，但复杂语境、跨句指代、矛盾陈述和复杂否定仍需人工判断；不构成完整的规范合规审查或自动指挥。
